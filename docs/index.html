Omics ML Explorer turns a set of R analysis scripts into a point-and-click interface: classifiers for a prostate-cancer protease panel, robust feature selection in pancreatic cancer (PDAC), and longitudinal biomarker monitoring in uveal melanoma.

Demo data only. All bundled datasets are simulated. They copy the structure of the real studies (column names, group sizes, visit layout) but contain no patient information. Each module also accepts your own CSV.

Module 1

Protease classifiers in prostate cancer

Can a panel of blood proteases tell prostate cancer apart from benign enlargement, and does it add anything to PSA?

  • Repeated random 80/20 train/test splits (stratified by class, optional)
  • SVM (linear, class-weighted, or radial), random forest, MLP, KNN, naive Bayes and GBM via caret::train, tuned with repeated k-fold CV on ROC
  • Feature presets: all proteases + PSA, proteases only, PSA only, or a custom set
  • Outputs: mean ± SD of training-CV and test AUC, accuracy, sensitivity and specificity; AUC spread across splits; ROC curves per split; per-split CSV

Simulated data: 60 BPH and 60 PCa samples, 10 proteases + PSA.

Module 2

Feature selection and classification in PDAC

Few patients and many proteins: which proteins are reliably informative, and how well does a small panel classify patients it has not seen?

Step 1: four complementary selectors

  • Stability selection: elastic net (glmnet) refit on many subsamples
  • Boruta: random forest compared against shuffled shadow features
  • RFE-CV: recursive feature elimination with repeated CV
  • mRMR: minimum redundancy, maximum relevance (praznik)

A consensus counts votes across the methods and ranks proteins with Robust Rank Aggregation. You choose how many votes a protein needs to join the panel.

Step 2: classify on held-out patients

The same six classifiers are tuned on the training split and tested once on the held-out 20%. By default, feature selection sees only the training split, so the test AUC is not inflated by selection bias.

Simulated data: 25 vs 25 patients, 80 Olink-style proteins.

Module 3

Longitudinal biomarker monitoring in uveal melanoma

Does a patient's biomarker leave the normal range during follow-up, and when?

  • A reference band is derived from control patients only: control mean ± z × residual SD of lm(Biomarker ~ days + ClinicalNumber)
  • Every measurement is flagged as significantly high (▲), significantly low (▼) or normal (●), and coloured by visit
  • Adjustable band width (z), group filter, patient highlighting and labels
  • Patient summary with flagged visits, day of the first high value and each patient's own trend; export as PNG or CSV

Simulated data: 10 control and 10 metastasized patients, 4 visits each.

Run the app

The app runs in R on your own computer. GitHub Pages hosts this page, but it can't run R, so the app itself needs a local R session or a Shiny server.

Straight from GitHub

# in R (version 4.1 or later)
install.packages("shiny")
source("https://raw.githubusercontent.com/sushmitapaul1/omics-ml-explorer/main/install.R")
shiny::runGitHub("omics-ml-explorer", "sushmitapaul1")

From a local copy

# in a terminal
git clone https://github.com/sushmitapaul1/omics-ml-explorer.git
cd omics-ml-explorer
Rscript install.R
Rscript -e 'shiny::runApp(launch.browser = TRUE)'
